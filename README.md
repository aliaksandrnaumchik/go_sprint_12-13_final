Todo Scheduler — веб‑сервер для управления задачами с повторением

Описание проекта
Todo Scheduler — это веб‑сервер на языке Go, который позволяет управлять задачами с возможностью повторения. Проект реализует REST API для работы с задачами и предоставляет веб‑интерфейс для их просмотра и редактирования.

Основные возможности:
- добавление задач с указанием даты, заголовка, комментария и правила повторения;
- редактирование существующих задач;
- отметка задач как выполненных (с автоматическим пересчётом даты для периодических задач);
- удаление задач;
- просмотр списка ближайших задач;
- получение деталей конкретной задачи;
- поддержка правил повторения задач (ежедневно, ежегодно, еженедельно, ежемесячно).

Список выполненных заданий
- реализация API для добавления задач (POST /api/task);
- получение списка ближайших задач (GET /api/tasks);
- получение данных задачи по ID (GET /api/task?id=<id>);
- редактирование задач (PUT /api/task);
- отметка задачи как выполненной с пересчётом даты (POST /api/task/done?id=<id>);
- удаление задач (DELETE /api/task?id=<id>);
- валидация входных данных (обязательные поля, корректность даты и правил повторения);
- работа с базой данных SQLite для хранения задач;
- веб‑интерфейс для взаимодействия с задачами.

Задания повышенной трудности не выполнялись.
